# 混凝土生产质量智能体本地验证链路

## 节点链路

```text
输入节点
  前端点击合格/异常批次，请求本地API
→ 数据库读取节点
  SQLite样例库读取批次信息 / 视觉特征 / 电流特征 / 配比参数 / 气象 / 运距 / 设备状态 / 质量规则
→ 规则判断节点
  C30目标范围、电流-坍落度关联、搅拌达稳时间、视觉异常
→ GLM质量研判节点
  质量判定、风险等级、关键证据、根因分析、处置建议
→ 分支与HITL节点
  合格分支：质检员确认后建议放行
  异常分支：人工确认调整/暂停后重新研判
→ 台账归档节点
  车次、标号、视觉结论、电流结论、配比结论、预测指标、最终判定、人工确认状态
```

## 证据边界

- 这是一条本地可运行的验证链路，用于证明输入、规则、模型研判、分支和台账输出可以闭环。
- 当前已补齐本地SQLite样例库和本地API联动：驾驶舱点击批次后，后端从样例库取数并调用Agent脚本。
- 当前未接入真实PLC、ERP、CQMS或生产视频流。
- HTML页面用于展示真实使用界面和交互方式；本地Agent用于证明判断链路能运行。
- SQLite样例库用于展示字段设计和数据流转，不代表真实客户生产数据库。
- 后续真实部署需要对接PLC/ERP/CQMS/视频流接口，并由现场质检员确认高风险动作。
